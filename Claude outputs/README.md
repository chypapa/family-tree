# Блог из группы ВКонтакте

Блок «Наш блог» на сайте сам показывает 4 последних поста из группы
[vk.ru/russiagenealogy](https://vk.ru/russiagenealogy): 1 большой и 3 маленьких.

## Как это работает

```
Группа ВК  ──►  api/vk-posts.php (на хостинге)  ──►  js/main.js  ──►  карточки блога
                 спрашивает ВК раз в 10 минут,
                 отбирает посты, чистит текст
```

- Ключ доступа к ВК хранится только на сервере, в браузер он не попадает.
- Ответ ВК сохраняется в `api/cache/` на 10 минут. Новый пост появится на сайте
  не позже чем через 10 минут после публикации в группе.
- Если ВК временно не отвечает, сайт показывает последний сохранённый список.

## Какие посты попадают на сайт

| В группе                              | На сайте                    |
|---------------------------------------|-----------------------------|
| Первое предложение со словом «здравствуйте» | Убирается               |
| Первая строка текста                  | Заголовок карточки          |
| Остальной текст                       | Основной текст (обрезается) |
| Первая картинка поста                 | Картинка карточки           |
| Эмодзи (везде)                        | Удаляются                   |
| Ссылки вида `[club123\|Архив]`        | Остаётся слово «Архив»      |
| Закреплённый пост                     | Не показывается             |
| Пост без картинки или без текста      | Не показывается             |
| Репост из другой группы, реклама      | Не показываются             |

## Что нужно, чтобы заработало

1. **Хостинг с PHP 7.4 или новее** — подходит почти любой обычный хостинг
   (Beget, Timeweb, REG.RU и т. п.). Расширения `curl` и `mbstring` обычно включены.
2. **Сервисный ключ ВК.**
   - Зайдите в кабинет VK ID для бизнеса: <https://id.vk.ru/about/business/go>.
   - Создайте приложение (тип — веб-сайт, адрес — адрес вашего сайта).
   - В разделе приложения скопируйте **«Сервисный ключ доступа»**. Срок у ключа не ограничен.
3. **Вставьте ключ** в файл `api/vk-config.php` вместо `ВСТАВЬТЕ_СЮДА_СЕРВИСНЫЙ_КЛЮЧ`.
4. **Загрузите всю папку сайта на хостинг**, включая папку `api`.
5. **Проверьте:** откройте `https://адрес-сайта/api/vk-posts.php` — должен показаться
   список постов в фигурных скобках. Потом откройте сам сайт.

Если открыть `index.html` двойным щелчком на компьютере, в блоге будут видны
заготовки «Название публикации» — посты подгружаются только с хостинга.

## Если посты не появились

Откройте `https://адрес-сайта/api/vk-posts.php` и посмотрите поле `error`:

| Ошибка            | Что делать                                                    |
|-------------------|---------------------------------------------------------------|
| `no_token`        | Ключ не вставлен в `api/vk-config.php`                        |
| `vk_error_5`      | Ключ неверный — скопируйте его заново                         |
| `vk_error_15`, `vk_error_30` | Группа закрыта — ключ приложения читает только открытые группы |
| `vk_unavailable`  | Хостинг не достучался до ВК — проверьте позже или спросите поддержку хостинга |

Страница вообще не открывается или показывает код PHP — на хостинге не включён PHP.

## Настройки (`api/vk-config.php`)

- `limit` — сколько постов показывать (сейчас 4, под вёрстку блока).
- `cache_ttl` — как часто спрашивать ВК, в секундах (600 = 10 минут).
  Меньше 60 поставить нельзя.
