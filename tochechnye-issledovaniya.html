Точечные генеалогические исследования и дизайн семейного дерева

Найдём нужный архивный документ, сведения о предке или подтверждение родства. Если история семьи уже собрана, создадим по вашим данным семейное древо с индивидуальным дизайном и подготовим его к печати.

Что входит в услугу

Можно заказать отдельный архивный поиск или дизайн семейного дерева по уже собранным сведениям.

В точечном исследовании решаем конкретную задачу: находим документ о предке, устанавливаем его личность, проверяем родственную связь. Объём поиска и стоимость обсуждаем индивидуально.

Для семейного дерева подбираем оформление, выстраиваем родственные связи и создаём векторную графику. Вы получаете файл и рекомендации для печати: древо можно увеличивать до нужного размера без потери качества.

Свяжитесь с нами, чтобы обсудить поиск или оформление вашего семейного дерева.

Для кого эта услуга?

  • Для тех, кому нужен конкретный архивный документ или сведения об одном предке
  • Для тех, кто ищет документы для подтверждения родства при оформлении наследства, гражданства или для суда
  • Для тех, кто уже собрал семейную историю и хочет оформить её в наглядное родословное древо
  • Для тех, кто готовит семейный подарок или хочет напечатать древо для дома
